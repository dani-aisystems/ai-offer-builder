# Fictional demo workflow

This walkthrough is a privacy-safe way to demonstrate the skill. **Northstar Bicycle Studio is fictional.** The people, brief, budget and package decisions below are invented for this demo; they are not a customer story or evidence of business results.

## Demo identity

- Business: Northstar Bicycle Studio
- Location: Bristol, United Kingdom
- Contact: Alex Morgan, `alex@northstar-bicycle.example`
- Agency: Example Studio, `hello@example-studio.example`
- Currency and tax: GBP, prices shown excluding VAT
- Package 1 budget: £1,500
- Offer type: website only

The `.example` domain is reserved for documentation and cannot be mistaken for a real client address.

## Prompt

```text
I am recording a public demo. Use demo mode and build a website offer for the fictional Northstar Bicycle Studio in Bristol. The contact is Alex Morgan at alex@northstar-bicycle.example. Use GBP, show prices excluding VAT, and use £1,500 as the Package 1 budget. Mark the deck visibly as a fictional demonstration. Do not imply that the business exists or that it achieved any results.
```

## Approval gates to show

1. Confirm the neutral demo identity or paste an equally fictional agency identity.
2. Review the research log. Keep only facts supported by pages opened during this run; remove unavailable or weak sources.
3. Review the three package definitions and prices. These are demo proposals, not market averages or customer purchases.
4. Approve the ten-slide plan only after checking that the fictional marker is visible.
5. Inspect the generated deck at desktop and phone sizes before showing it publicly.

## Expected artifacts

- `offer-deck-northstar-bicycle-studio.html`
- `Offer record (internal).md`

The file names describe expected output types, not committed golden files. Generated copy, research and layout can vary between runs because the workflow uses a model and live web sources.

## What this demo proves

It demonstrates the staged workflow, approval gates, output structure, language/currency handling and privacy controls. It does **not** prove sales conversion, market performance, factual accuracy beyond the reviewed sources, or suitability for a real client without human review.
